# ChatPDF
This is a AI project using Ollama and Langchain to achieve PDF reading. 

## 2025 11 10 
Do nothing.

## 2025 11 12
Create a web that can upload a file and decorate it.

## 2025 11 13
After upload the file, it redirects to another web that displays the pdf on the left panel and a chat box on the right panel.

## 2025 11 17
Integrated a local LLM (Ollama) with a Flask-based web interface that allows users to ask questions in the chat box and is able to answer users' questions and display answers in the browser panel.

## 2025 11 19
Extracted full text of uploaded PDF and send the text to Ollama together with users' question, make Ollama answer users' questions according to the content of PDF. Change Q&A panel to streaming AI responses and make it diaplay chat history.
